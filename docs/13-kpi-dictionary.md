# 13 · Diccionario de KPIs

| KPI | Fórmula | Fuente de datos | Frecuencia |
|---|---|---|---|
| CPL | Inversión / leads | Meta Ads + CRM | Semanal |
| CTR | Clicks / impresiones | Meta Ads | Semanal |
| Conversión landing | Leads / visitas landing | Landing + CRM | Semanal |
| Conversión formulario | Formularios enviados / visitas formulario | Formulario + analítica | Semanal |
| Contact rate | Leads contactados / leads totales | CRM | Diario/Semanal |
| Appointment rate | Citas agendadas / leads totales | CRM | Semanal |
| Show-up rate | Citas asistidas / citas agendadas | CRM | Semanal |
| Close rate | Ventas cerradas / presentaciones | CRM | Semanal/Mensual |
| Costo por cita | Inversión / citas agendadas | Ads + CRM | Semanal |
| Costo por cliente | Inversión / ventas cerradas | Ads + CRM | Semanal/Mensual |
| ROI | (Ingresos - inversión) / inversión | CRM + financiero | Mensual |
| Prima promedio | Prima total / ventas cerradas | CRM/financiero | Mensual |

## Reglas
- Mantener una sola definición por KPI.
- Documentar fecha de última actualización de métricas.

## Pendientes de validación humana
- Confirmar fuente financiera oficial para ROI y prima.
